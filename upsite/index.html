Upsite — B2B Web App

  • Client

    Fabloo

  • Role

    Lead Designer (Team of 6)

  • Platform

    B2B SaaS (Web)

  • Duration

    3 months

1. Overview & Role

Upsite is a B2B e-commerce back-office platform empowering online merchants to manage multi-channel orders, catalog variations, inventory, and revenue reporting. As the Lead Product Designer, I directed and mentored a cross-functional team of 6 designers to overhaul the legacy platform, scaling it from a fragmented UI into a highly dense, enterprise-ready workspace.

2. The Problem

Before our team's intervention, the initial version was built with arbitrary styling and low usability considerations for enterprise workflows:

  • Wasted Screen Real Estate: Massive decorative banners pushed mission-critical order and revenue data completely below the fold.
  • Missing Data Management Patterns: Core views lacked global search, status filters, bulk select actions, and sorting.
  • High Visual Fatigue: Over-saturated neon purple container headers and inconsistent card borders made prolonged operational work exhausting for store managers.

3. UX Redesign Breakdown: Before & After

Below is a direct comparison of the key workflows our team redesigned to establish high visual scannability, predictable data grids, and structured component hierarchy.

Workflow 01 · Overview

Merchant Command Center & Analytics

Legacy UI Low Density / Obstructed Fold
Friction Points:
  • Oversized welcome banner consumed 30% of the viewport with zero actionable data.
  • KPI cards used non-standardized 3D icons with poor metric alignment.
  • Orders section relegated to an empty card with no scannable trend visualization.
Redesigned UI High Scannability / 6 Core KPIs
Enhancements:
  • Structured 6-metric summary bar surfacing live revenue, customers, and active products.
  • Integrated 7-day revenue trend chart alongside an actionable Recent Orders table with status chips.
  • Added global navigation search, store detail panel, and quick management links.
Workflow 02 · Catalog Architecture

Brand Catalog & Inventory Grid

Legacy UI Zero Data Discovery Tools
Friction Points:
  • Generic empty card with no contextual guidance or onboarding cues.
  • Missing global search, pagination, bulk selection, and sort functions.
  • Action button isolated in an awkward floating top-left position.
Redesigned UI Enterprise Data Grid
Enhancements:
  • Complete multi-column data table: avatar initials, domains, countries, product counts, and revenue.
  • Filter control toolbar combining search, status dropdown, alphabetical sort, and primary "+ Add Brand" CTA.
  • Added bulk checkboxes, status badges (Active/Inactive/Featured), and inline row action triggers.
Workflow 03 · Product Variations

Attribute Terms & Variant Management

Legacy UI Stacked Empty Containers
Friction Points:
  • Attributes rendered as endlessly stacked vertical empty cards without tabbed separation.
  • No visual previews for visual attributes (e.g., color swatches or hex values).
  • Zero visibility into sort order, associated product counts, or slug identifiers.
Redesigned UI Tabbed Variant Matrix
Enhancements:
  • Tabbed attribute navigation (Color, Size, Material, Storage, Weight) with live item count badges.
  • Visual color swatches paired with hex badges, slugs, and descriptive labels.
  • Standardized sorting order numbers, linked product totals, and inline "+ Add another term" shortcut.

4. Design System Foundations

The entire interface was transitioned from ad-hoc styling to a scalable design token architecture created and maintained by our design team:

Color Hierarchy

Replaced saturated purples with a calm neutral gray scale (`#F8F9FA` through `#1F2937`) anchored by an accessible primary brand blue (`#1570EF`) for focused interactive states.

Data Density

Introduced a strict 8px layout grid with standardized 40px table row heights, consistent badge padding, and fluid typography tokens for high scannability.

Front-End Parity

Structured Figma components into auto-layout atomic tokens matching CSS Flexbox properties, drastically reducing engineering QA cycles.

5. Measurable Outcomes

  • ✦ 65% Faster Product & Brand Catalog Management Time
  • ✦ 100% WCAG AA Contrast Compliance across all tables and inputs
  • ✦ Zero Horizontal Scroll Dependency on Standard Desktop Displays
